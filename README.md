# RIFT Browser
# THIS IS RIFT V1 SO DONT EXPECT SOMETHING ALREADY DONE.

RIFT is a small, experimental browser built in Python.

The idea behind RIFT is pretty simple: instead of trying to make another browser that does everything for you, RIFT gives you control over how the browser is configured and behaves.

You start by configuring it yourself through commands, choosing things like the search engine, theme, downloads location and other settings. Once the configuration is finished, RIFT launches into its graphical interface.

## Why RIFT?

I wanted to experiment with what a browser could feel like if it was:

- Lightweight and conscious about RAM usage
- Highly configurable
- Themed and customizable
- Configured manually instead of relying on huge setup menus
- Simple enough to understand and modify
- Built as a single Python project

RIFT is also an experiment. Things will break, features will change, and some parts are still rough.
